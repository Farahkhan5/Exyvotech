# Exyvotech 🚀

Exyvotech is a modern and responsive digital agency website developed using PHP, HTML, CSS, JavaScript, and Bootstrap 5.  
The project showcases innovative digital services including web development, app development, cyber security, digital marketing, SEO content writing, branding solutions, and POS solutions.

---

# 🌟 Features

- Dynamic Hero Section with Rotating Content Slider
- Interactive Particle Background Animation
- Fully Responsive Modern UI
- Bootstrap 5 Based Design
- Animated Marquee Section
- Professional About Section
- Services Showcase Cards
- Expertise & Statistics Section
- Why Choose Us Section

- Features Section

# 🚀 Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Farahkhan5/Exyvotech.git
```

---

## 2️⃣ Move Project Folder

Move the project folder into:

```text
C:\xampp\htdocs\
```

---

## 3️⃣ Start Apache Server

Open XAMPP Control Panel and start:

- Apache

---

## 4️⃣ Run Project

Open browser and visit:

```text
http://localhost/exycotech
```
